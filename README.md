## Install

**Option A — copy it yourself.** Save `AGENT_POLICY.template` to your repo root as `AGENTS.md` (or `CLAUDE.md`), then start your agent. It completes the Bootstrap section and removes it.

**Option B — let the agent do it.** Tell your agent:

> Install https://raw.githubusercontent.com/aulimaru/agents/master/AGENT_POLICY.template into this project as AGENTS.md.
