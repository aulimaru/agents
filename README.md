## Install

**Option A — copy it yourself.** Save `AGENT_POLICY.template.md` to your repo root as `AGENTS.md` (or `CLAUDE.md`), then start your agent. It will walk you through setup, then remove the Bootstrap section.

**Option B — let the agent do it.** Tell your agent:

> Install https://raw.githubusercontent.com/aulimaru/agents/master/AGENT_POLICY.template.md into this project as AGENTS.md.
